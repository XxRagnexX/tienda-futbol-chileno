# Tienda Fútbol Chileno

Proyecto desarrollado para la asignatura Desarrollo Fullstack II de Duoc UC.

La aplicación corresponde a una tienda online enfocada en ropa y camisetas de equipos del fútbol chileno, inicialmente de clubes de Primera División.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Git
- GitHub

## Funcionalidades

- Página principal de la tienda
- Catálogo de productos
- Visualización de camisetas de fútbol chileno
- Detalle de productos
- Carrito de compras
- Navegación entre páginas
- Formularios y validaciones con JavaScript
- Sección administrativa
- Diseño responsivo
